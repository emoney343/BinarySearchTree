# Binary Search Tree File System
 
A command-line file system simulator written in Java. Built as a hands-on data structures project — the tree is implemented from scratch and keeps all files and folders sorted alphabetically at all times.
 
## How to Run
 
```bash
javac *.java
java Main
```
 
## Features
 
- Add files (with size) or folders
- Search for a file or folder by name
- Delete a file or folder
- Update an existing entry's name, type, or size
- Retrieve a file or folder by index
- List all entries in alphabetical order
 
## What I Learned
 
- How a binary search tree works - inserting and searching by comparing values left or right at each node
- How recursive algorithms navigate and modify a tree structure
- How deletion works in a BST, including the three cases: no children, one child, and two children
- How in-order traversal (left → current → right) produces a naturally sorted list without any extra sorting step
